# School blueprints

These JSON files are retained historical school-style summaries. They are not used to generate unchecked live model answers. The running generator does not read uploaded PDFs. A summary file is not evidence of completed source ingestion or a verified 2027 exam specification.

Source reconciliation is tracked in docs/paper-audit/source-reconciliation-2026-10-20.md. Original practice must not be represented as a school past paper. Future ingestion needs document identity, source year, inspected pages, extracted skill evidence, rights status and reviewed mappings before activation.

25October2026: current source checks are in data/schoolPaperEvidence.ts. School selection serves reviewed general-bank questions with explicit non-simulation metadata. Historical blueprint timing/format weights do not set public exam claims or official timing defaults.
